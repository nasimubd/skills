# Norn Codex plugin

This package gives Codex the same Norn setup, doctor, and task-routing capability as the Claude marketplace plugin. It installs the external Norn runtime and leaves Argus credentials and optional Agent-S installation to their own setup flows.

Install this plugin from the `codex-plugins/norn-agent` directory with the Codex plugin tooling, then use the bundled `norn-agent` skill for setup and routing.
